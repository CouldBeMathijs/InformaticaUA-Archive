Er zijn 4 types:\\
- Discover: 1, 15\\
- Offer: 3, 17\\
- Request: 4, 13, 18, 31, 33, 43, 49\\
- ACK: 6, 14, 20, 32, 34, 44, 50\\

Doel:\\
- Discover: client meldt het netwerk dat ie op zoek is naar een IP-adres\\
- Offer: Server antwoordt met een IP-adres en hoe lang het gebruikt mag worden\\
- Request: client accepteert het of vraagt om een verlenging van zijn lease\\
- ACK: Server bevestigd een request
